Aufsätze anonymisieren

Holt die Aufsätze einer Klasse aus mehreren exam.net-Prüfungen und gibt allen Schüler/innen einen festen Codenamen (z. B. «Grauer Fuchs»), der über alle Aufsätze gleich bleibt. So lassen sich Entwicklungen über mehrere Aufsätze mit einer KI untersuchen, ohne dass sie Namen sieht.

Einrichten

Ziehe diesen Knopf in deine Lesezeichenleiste (einmalig):

Aufsätze anonymisieren

Lesezeichenleiste nicht sichtbar? In Chrome: Cmd + Shift + B (Mac) bzw. Ctrl + Shift + B (Windows).

Gebrauch

  1. Bei exam.net einloggen (irgendeine Seite, z. B. die Testübersicht).
  2. Auf das Lesezeichen Aufsätze anonymisieren klicken.
  3. Klasse (Ordner) wählen, dann die Prüfungen.
  4. Optional den Schlüssel vom letzten Mal laden, damit alle denselben Codenamen behalten.
  5. Rückfragen beantworten (siehe unten), Schüler/innen wählen, Format wählen, herunterladen.
  6. Schlüssel herunterladen und gut aufbewahren.

Wie erkennt das Tool, wer wer ist?

  • E-Mail: Ist sie vorhanden (Schul-Login in exam.net), ist die Zuordnung eindeutig.
  • Name: Gleich geschriebene Namen in verschiedenen Prüfungen gelten als dieselbe Person.
  • Rückfrage bei ähnlichen Namen («Peter» / «Peterr» / «Peter2»), bei gleichem Gerät mit anderem Namen und wenn ein Name in derselben Prüfung zweimal vorkommt (z. B. neu eingeloggt). Das Tool entscheidet dann nicht selbst, du entscheidest.

Tipp: In den exam.net-Einstellungen der Prüfung das Schul-Login (Microsoft) verlangen. Dann ist die E-Mail dabei und es gibt kaum Rückfragen.

Was heruntergeladen wird

  • Texte als Markdown (.md), wahlweise pro Schüler/in (Ordner oder eine Datei), pro Aufsatz oder alles in einer Datei. Die Aufsätze sind nach Datum nummeriert (1 = ältester). Dazu eine Übersicht.md.
  • Im Text werden Namen und E-Mail-Adressen durch den Codenamen ersetzt, auch Namen von Mitschüler/innen. Ist ein Name mehrdeutig (zwei Personen gleichen Vornamens), steht «[Name]». IP-Adresse, Gerät und Browser kommen nicht mit.
  • Der Schlüssel (.csv, öffnet in Excel) enthält Codename, E-Mail, alle Schreibweisen des Namens und die Geräte. Ihn nie der KI geben.

Vor dem Download prüft das Tool, ob im Text noch eine E-Mail-Adresse oder ein bekannter Name steht, und warnt dann. Namen, die zugleich gewöhnliche Wörter sind, werden mitersetzt.

Ohne exam.net: Dateien hochladen

Für Aufsätze aus anderen Quellen oder als Ersatz, falls das Lesezeichen nicht funktioniert. Word, Text oder ZIP, eine Datei pro Abgabe, Name im Dateinamen.

Datenschutz

Alles läuft in deinem Browser. Weder Namen noch Texte werden irgendwohin geschickt. Diese Seite liefert nur das Programm.

Grenzen

Das Tool nutzt keine offizielle Schnittstelle von exam.net. exam.net kann seine Seite jederzeit ändern. Funktioniert das Lesezeichen plötzlich nicht mehr, liegt es meist daran.
